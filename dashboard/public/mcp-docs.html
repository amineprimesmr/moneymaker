MoneyMaker dans ton assistant

Demande à Claude ou ChatGPT « combien j'ai gagné cette semaine ? », « pourquoi mon MRR a baissé ? », « quels pays convertissent le mieux ? »… L'assistant lit tes revenus, abonnés, clients, classements, avis et ta finance, et peut modifier ta configuration avec ton accord.

Adresse du serveur : https://moneymaker-io.web.app/mcp. Une seule étape : Se connecter avec MoneyMaker.

Claude (claude.ai, Claude Desktop, mobile)

  • Le plus simple : ouvre la fiche MoneyMaker de l'annuaire Claude › Connecter › Autoriser.
  • Ou à la main : menu de gauche › Personnalisation › Connecteurs › + Ajouter (en haut à droite) › Ajouter un connecteur personnalisé.
  • Nom : MoneyMaker · URL : https://moneymaker-io.web.app/mcp → Ajouter, puis Se connecter.
  • Connecte-toi à MoneyMaker, choisis lecture seule ou lecture + modification, Autoriser. C'est tout.

Claude Code

claude mcp add --transport http moneymaker https://moneymaker-io.web.app/mcp

Puis /mcp › moneymaker › Authenticate : le navigateur s'ouvre sur MoneyMaker. Ou le plugin (connecteur + skill d'analyse) :

/plugin marketplace add amineprimesmr/moneymaker
/plugin install moneymaker@moneymaker

ChatGPT

  • Réglages › Applis et connecteurs › Paramètres avancés › active le mode développeur.
  • Créer : nom MoneyMaker, URL https://moneymaker-io.web.app/mcp, authentification OAuth.
  • ChatGPT ouvre la page MoneyMaker : connecte-toi et Autorise. Dans une conversation, active MoneyMaker depuis le menu +.

Sans OAuth (secours, scripts, autres clients)

Crée un jeton personnel mm_pat_… (Dashboard › Compte) et passe-le en en-tête :

claude mcp add --transport http moneymaker https://moneymaker-io.web.app/mcp --header "Authorization: Bearer mm_pat_xxx"

Cursor, Codex, Windsurf… : même URL, en OAuth ou avec l'en-tête Authorization. Client stdio uniquement : MM_TOKEN=mm_pat_xxx node tools/mcp/index.js (dépôt GitHub).

Sécurité

  • L'assistant agit avec tes droits sur chaque business (owner, admin, developer, viewer) et chaque modification apparaît dans le journal d'audit.
  • Les clés des stores (Stripe, App Store Connect, Google Play, PostHog) ne sont jamais lues ni modifiées par l'assistant.
  • Les suppressions (membre, invitation, dépense, app suivie, PostHog, retrait d'accès) demandent ta confirmation explicite.
  • Accès valable 90 jours, révocable à tout moment sur /connect.
